# 🌸 EdgeTunnel · 二次元个人主页版

> 一个基于 [EdgeTunnel](https://github.com/cmliu/edgetunnel) 修改的二次元风格个人主页。
>
> Vibe Coding 制作 · 可自行修改 · 可作为自己的个人主页使用

本项目基于佬儿 [cmliu/edgetunnel](https://github.com/cmliu/edgetunnel) 的代码进行修改，在保留原项目核心功能的基础上，对前端页面进行了重新设计，加入了一个偏二次元风格的个人主页。

你可以直接 Fork 本项目，根据自己的喜好修改页面中的文字、图片、链接等内容，将它制作成属于自己的个人主页。

---

## ✨ 项目特色

- 🌸 **二次元风格个人主页**
- 🖥️ **基于 EdgeTunnel 修改**
- 💬 **接入每日一言**
- 📖 **接入每日诗词**
- 🖼️ **使用二次元背景图**
- ✏️ **页面内容可以自行修改**
- ☁️ **可以继续使用 Cloudflare Workers 部署**
- 🤖 **Vibe Coding 制作**

---

## 🔗 使用的接口与资源

### 💬 每日一言
使用 [Hitokoto 一言](https://hitokoto.cn/) 提供的接口：
- `https://v1.hitokoto.cn/`
- 用于页面中的每日一言展示。

### 📖 每日诗词
使用 [今日诗词](https://www.jinrishici.com/) 提供的每日诗词接口：
- 🌐 [https://www.jinrishici.com/](https://www.jinrishici.com/)

### 🖼️ 二次元背景图
背景图片使用 栗次元 API：
- `https://t.alcy.cc/`
- 🌐 [https://t.alcy.cc/](https://t.alcy.cc/)

感谢相关 API 服务提供背景图片资源。

## 🎨 自定义你的主页

这个版本并不是为了做成一个固定样式的项目，而是希望提供一个可以直接修改的个人主页模板。

你可以根据自己的需求修改：

- 👤 个人昵称
- 📝 个人介绍
- 🔗 GitHub / 社交平台链接
- 🌐 网站链接
- 🖼️ 背景图片
- 🎨 页面样式
- 📌 页面中的其他文字内容

如果你不喜欢现在的内容，直接修改前端代码即可。把里面的文字、图片、链接改成你自己的内容，就可以把它变成一个属于自己的二次元个人主页。
